学习设置

数据管理

全部数据只存在本机浏览器 localStorage，可随时导出备份到本地文件。

安全提醒：语音 key 不会写入文件，只在你自己设备的浏览器里保存；即使仓库公开部署，别人也看不到你的 key。

关于与更新

手机访问：把本文件部署到静态托管（如 GitHub Pages）后，手机打开链接即可使用。以后我推送新版后，手机打开页面会自动检测并刷新到新版，无需手动操作。打卡数据保存在各设备本地，跨设备请用"导出/导入备份"。
